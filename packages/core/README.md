# @sorbet-ui/core

Shared types (`SorbetVariant`, `SorbetColor`, `SorbetSize`), variant presets, accessibility helpers and headless state helpers used by `@sorbet-ui/react`. Most apps don't need to install it directly; it comes with `@sorbet-ui/react`.

```bash
npm i @sorbet-ui/core
```
